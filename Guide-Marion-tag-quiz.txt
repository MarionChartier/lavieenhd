Coucou Marion !

Bonne nouvelle : les inscriptions des deux quiz arrivent bien dans ton systeme.io (j'ai teste, le contact se cree avec le prenom et l'email). Il manque juste UN reglage de ton cote : le TAG n'est pas applique automatiquement. C'est pour ca que tu avais l'impression que "ca ne marchait pas" : les contacts arrivaient, mais sans tag, donc invisibles dans ta vue filtree par tag.

On corrige ca avec une petite "regle d'automatisation". A faire 2 fois (une par quiz). Tes deux formulaires sont dans le meme tunnel, qui s'appelle : "Formulaires pour Quiz".

------------------------------------------------------------
REGLE 1 - Quiz environnement (le lieu de vie / de travail ideal)
------------------------------------------------------------

1. En haut, clique sur "Automatisations", puis sur l'onglet "Regles".

2. Clique sur "Creer" (en haut a droite).

3. Le declencheur (= ce qui lance l'action) :
   - Clique sur le "+" sous "Declencheur".
   - Choisis "Inscription sur la page (optin)".
   - On te demande quelle page : choisis le tunnel "Formulaires pour Quiz",
     puis la page correspondant au QUIZ ENVIRONNEMENT (lieu de vie / de travail ideal).

4. L'action :
   - Clique sur le "+" sous "Action".
   - Choisis "Ajouter un tag".
   - Selectionne le tag : "Quiz - Lieu ideal".

5. Clique sur "Sauvegarder la regle". C'est fait pour le 1er quiz.

------------------------------------------------------------
REGLE 2 - Quiz alignement vie pro
------------------------------------------------------------

Refais exactement les memes etapes 2 a 5, mais cette fois :
   - Declencheur : la page du QUIZ ALIGNEMENT VIE PRO (dans le tunnel "Formulaires pour Quiz").
   - Action : tag "Quiz - Alignement pro".
   - Sauvegarde.

------------------------------------------------------------
IMPORTANT
------------------------------------------------------------

- La regle ne s'applique qu'aux NOUVELLES inscriptions faites APRES sa creation.
  Elle ne re-tague pas les anciens contacts.

- Pour verifier : refais un quiz avec une fausse adresse, puis va dans "Contacts"
  et regarde que le bon tag apparait bien sur ce nouveau contact.

- Si a l'etape 3 tu ne vois qu'UNE SEULE page pour les deux quiz (et pas deux pages
  distinctes), dis-le moi : ca voudra dire que les deux formulaires partagent la meme
  page d'inscription, et on passera par les reglages du formulaire lui-meme. Je te
  guiderai.

Merci a toi ! Une fois ces 2 regles en place, chaque participant sera tague tout seul. :)
